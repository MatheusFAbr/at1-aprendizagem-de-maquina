
# AT1 — Perceptron e KNN em Prática

Atividade da disciplina de Aprendizagem de Máquina da FATEC, desenvolvida em Python com NumPy e Jupyter Notebook.

## Desafios

1. **Perceptron:** treinamento de um modelo para classificar transações financeiras como legítimas ou suspeitas.
2. **KNN:** classificação do risco de cancelamento de clientes SaaS utilizando distâncias Euclidiana e Manhattan.
3. **Recomendação de servidores:** identificação dos servidores Cloud mais próximos das especificações solicitadas, utilizando distância Euclidiana.

## Tecnologias

- Python
- NumPy
- Jupyter Notebook

## Como executar

1. Clone o repositório.
2. Instale as dependências com `pip install numpy jupyter ipykernel`.
3. Abra o arquivo `at1_am.ipynb` no VS Code ou Jupyter Notebook.
4. Execute todas as células em sequência.
